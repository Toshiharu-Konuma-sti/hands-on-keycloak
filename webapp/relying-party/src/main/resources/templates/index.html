Relying Party (RP)

IdP(Keycloak) → RP(この画面) → RS(Resource Server) の流れを体験する。 このアプリは「経費精算」を題材にしている。申請アプリと承認アプリ、一般社員(staff.sios)と上長(admin.sios)を切り替えて試す。 スコープは「アプリ(RP)に許した操作」、ロールは「ユーザーに与えられた役割」。 APIは、その両方を見て許可するかを決める。

1. ログインする

アプリ(client_id):

  • expenses:read は default scope のため、常に付与される。
  • expenses:write / expenses:approve は optional scope のため、要求したときだけ付与される。
  • 承認アプリには write、申請アプリには approve は割り当てていない。
(ユーザー: admin.sios / staff.sios / taro.sios、パスワードはユーザー名と同じ)
